# Portafolio personal

Portafolio web de Carlos Andrés Hidalgo Bolaños, Ingeniero de Sistemas y Computación y desarrollador de software.

## Contenido

El sitio presenta:

- Perfil profesional y datos de contacto.
- Experiencia en Davivienda S.A. y Construcciones y Transportes JMC SAS.
- Proyectos de desarrollo web, móvil y full stack enlazados a GitHub.
- Tecnologías organizadas por categorías, sin indicadores porcentuales.
- Formación académica y certificaciones con credenciales disponibles.
- Descarga de la hoja de vida en PDF.

## Tecnologías

- HTML5 semántico
- CSS3 con diseño responsive, tema claro/oscuro y animaciones sutiles
- JavaScript nativo para navegación, filtros, tema y revelado al hacer scroll
- Font Awesome y Google Fonts mediante CDN
- Netlify para despliegue

## Desarrollo local

El proyecto es estático y no requiere instalación de dependencias. Puede abrirse directamente desde `index.html` o servirse con cualquier servidor HTTP estático.

Los recursos locales se encuentran en `assets/`:

- `assets/img/profile.png`
- `assets/img/CV Carlos Hidalgo.pdf`
- `assets/certificados/`
